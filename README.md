# Social Media App

A full-stack social media web application built using the MERN stack. 
The application provides users with a platform to create posts, interact with other users, comment on posts, and receive real-time interactions.

## 🚀 Features

- User Registration and Login
- JWT-based Authentication
- Create, Edit and Delete Posts
- Like and Comment on Posts
- Real-time Comment Interaction using Socket.IO
- User Profiles
- Follow/Unfollow Users
- View Posts from Other Users
- Image Upload
- Search Users
- Responsive User Interface
- RESTful APIs for Backend Services

## 🛠️ Technologies Used

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

### Real-Time Communication
- Socket.IO

### Other Tools
- Git & GitHub
- Cloudinary
